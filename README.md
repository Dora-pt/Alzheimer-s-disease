## 开发模型

**迭代式生命周期**：全程覆盖课程七个生命周期阶段，**总工期 9 周**，分 5 个迭代（I1–I5）执行，每个迭代完成「细化需求 → 设计 → 编码 → 单元测试 → 演示评审」微循环，增量交付。详见《迭代计划-总表-v2.0》。
