## A. P0 关键问题（决定技术与范围，必须先答）

### Q1｜一期录入范围

- **问题**：33 页的 SCD 主表，是全部电子化，还是只做其中「H 神经心理量表」部分？
- **背景**：SCD 主表包含 A 一般资料、B 既往史、C 个人史、D/E 主观认知问卷、F 现病史、G 化验、H1–H16 十六套量表、I 生物标记物、J 诊断、K 随访，共约数百个字段。
- **影响**：全表工程量约为只做 H 部分的 2–3 倍，直接决定迭代数量与人员配比。
- **我们的建议**：全部录入，但按优先级别分两批：H 部分（认知测验主体）与 A/D/E（受试者与主观问卷）为第一批；B/C/F/G/I 等临床背景为第二批。
- **优先级**：P0
- **客户答复**：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

### Q2｜量表计分要不要系统自动计算

- **问题**：CDR 总体分级、CDR-SB、ADAS-cog 总分、ADAS 三次回忆平均值、各量表总分，是否由系统自动计算？
- **背景**：客户说明"一期不需要对输入的数据进行分析，只需保存、查询、统计"。但 CDR 分级、ADAS 总分属于**量表本身的评分规则**，与"跨表数据分析"是两回事；CDR 总体分级规则复杂（主项+5 次要项+就近联合），人工易错。
- **影响**：若自动计算，需要实现规则引擎并在界面呈现推导过程；若只存原始分，界面仅保留医生手工填写的结论。
- **我们的建议**：一期做"单表内自动求和/分级"（CDR、ADAS、各量表总分），不做跨表分析与诊断建议；同时保留手工覆盖入口。
- **优先级**：P0
- **客户答复**：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

### Q5｜"语音输入"的具体形态

- **问题**：项目说明中"可考虑采用……语音输入"，具体指哪一种或哪几种？
  1. 系统读题（TTS，机器朗读题干给受试者）；
  2. 语音作答转文字（ASR，用于自由文本题，如现病史、CDR 事件描述）；
  3. 语音指令选择选项（受试者说"是/否/第 3 个"，系统勾选）。
- **影响**：三种方案的技术组件、接口成本、测试工作量差异很大；2 与 3 涉及识别准确率与方言问题。
- **我们的建议**：一期优先做 1（读题）+ 2（自由文本听写，调用成熟云服务），3 列为二期。
- **优先级**：P0
- **客户答复**：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

### Q12｜交付形态

- **问题**：系统以什么形态交付：网页（浏览器）、平板 App、电脑桌面软件？
- **背景**：受试者多为老年人，触摸操作、字号、按钮尺寸是重要约束；项目说明未指定形态。
- **影响**：直接决定技术栈、部署方式与工作量。
- **我们的建议**：Web 应用（响应式），医生端用电脑，施测端用平板浏览器全屏打开；一套代码覆盖两种场景。
- **优先级**：P0
- **客户答复**：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

### Q7｜离线使用

- **问题**：项目说明中"系统离线也可使用……（可选）"，一期是否为硬性要求？
- **影响**：离线会显著增加架构复杂度（本地存储、冲突合并、同步策略）。
- **我们的建议**：一期不做，作为二期功能；或做成"断网时本地暂存、联网后补传"的轻量方案。
- **优先级**：P1
- **客户答复**：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

- **问题**：多医院使用时，中心编号、受试者编号的规则是什么？数据合并时出现冲突如何处理？
- **我们的建议**：采用「中心编号-受试者编号-访视序号」复合主键；合并时以中心内唯一编号去重。
- **优先级**：P1
- **客户答复**：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

### Q9｜角色与协作录入

- **问题**：医生、研究者、受试者、家属各自的权限？同一次访视是否允许不同人分别填写不同部分？
- **背景**：一次施测中受试者、知情者、评定者分角色填写；完整评估跨 1.5–2 小时，可能分时段完成。
- **我们的建议**：一期做角色区分（管理员/评估者）+ 每条记录留填写者与时间戳；暂不做复杂审批流。
